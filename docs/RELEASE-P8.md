# P8 整合与验收（2026-11-06）

## 已交付
- 统一探索入口与父级/全景导航；图鉴覆盖28个天然天体与4个人造航天器，支持中日英和编号搜索、天然/人造分类。
- 单一图层面板根据视图呈现轨道、名称、区域、彗星及任务路线；所有视图均可打开显示设置、画质和减少动态效果。
- 修复航天器缩放时丢失选择、进入外围后不能恢复人造卫星视角；保留任务独立时钟与相机快照恢复。
- 减少动态效果冻结公转、自转、彗尾活动与任务播放，相机立即切换、关闭拖动惯性；柯伊伯点云使用静态显隐，避免渐显与逐步增密。手动播放可显式恢复运动，刷新仍按用户要求默认自动播放。
- 原生键盘路径、焦点丢失后的导航回退和至少44px控件目标；手机触控模拟完成区域、任务和节点流程。
- 清理旧“后续开放”说明；将阶段计划、科学快照、截图与性能证据纳入项目文档白名单，保留本地面试笔记的忽略规则。

## 验证结果
79/79项测试、类型检查、生产构建和dist完整性验证通过。浏览器覆盖：统一搜索/分类、卫星父级往返、代表小天体图层隐藏、彗尾开关/公共时间、航天器缩放及外围返回、任务时钟与共享设置、三语、键盘、触控、图片加载失败降级和WebGL上下文丢失后重试。

生产5178预览验证通过：DEV调试与贴图故障参数被剔除、所有运行资源请求为本地文件、奥尔特云→新视野号→奥尔特云恢复正确。该验收阶段尚未部署；用户后续已授权发布，执行记录见DEPLOYMENT.md。

36组性能记录：本机Edge，桌面与手机触控模拟，9个视图×2档画质×2种屏幕条件。实际渲染器为Intel Iris Xe / ANGLE D3D11。每种屏幕5轮跨视图循环后，几何数量均54→54、纹理26→26。原始样本见 `performance/p8-measurements.json`；回调间隔不是GPU耗时或手机真机FPS。

## 仍未完成的验收
**实体手机性能验证未完成，因此不将整个P8标为全部验收完成。** 当前只有同一Windows主机的390×844触控模拟，没有可直接访问的实体手机。还需至少记录一台iOS/Safari或Android/Chrome的型号、系统/浏览器、DPR、各阶段帧耗时和持续运行后的内存/发热；若超出预算，再降低该设备默认预算。保留计划原始验收项，未用模拟结果替代真机。

构建仍有原有Three/R3F场景chunk大于500kB的提示；未作跨硬件、长时间泄漏或GPU时间保证。静态产物准备完成，发布应按用户后续指令执行。

## 可重复检查
Node24：`npm run typecheck`、`npm test`、`npm run build`、`npm run check:dist`。可选浏览器脚本：准备Playwright与Microsoft Edge，启动5176开发服务后从仓库根目录运行 `node scripts/verify-ui.mjs`、`node scripts/measure-performance.mjs`。脚本默认使用本机Edge与固定端口；项目网页运行不依赖Playwright。
