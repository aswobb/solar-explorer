# P5：哈雷彗星与椭圆轨道

## 操作
探索入口、图鉴分类和名称搜索均能选中哈雷并平滑跟随。近日点/远日点按钮定位公共展示时钟，同时更新所有天体、自转和视觉效果，并暂停以便观察；继续播放后按当前倍率前进。离子尾背离太阳；尘埃尾在背日方向基础上，向轨道运动的滞后方向弯曲。彗发/双尾可独立关闭，彗核继续可选。隐藏当前彗星返回全景。

## 科学参考与展示边界
JPL SBDB 1P 快照：`data/halley-sbdb.json`；历元 JD 2439875.5 TDB，观测弧1835-08-21至1994-01-11，解算日期2025-11-21。半长轴17.92863504856923 AU，偏心率0.9679359956953211，倾角162.1905300439129°，升交点59.09894720612437°，近日点幅角112.2414314637764°，参考周期27728.04608790421天。来源快照包括数值精度与参考文献，不将其视为无误差测量。

彗核有效直径11 km换算半径5.5 km，不冒充精确球形平均半径。外形拉长，表面、自转仅为示意；数据源未给出可靠单一自转周期，因此详情不填造自转科学值。

画面为可观看性采用 a=24 场景单位、e=0.78，使近日点5.28在放大太阳之外，远日点42.72。保留参考倾角和轨道定向；初始平近点角人为取0，不采用快照的历元相位。倾角大于90°自然形成逆行，无第二次反向。开普勒方程决定展示椭圆上的非匀速运动，兼容路径保留原行星、卫星、小天体的圆轨道。

彗尾强度使用同一平近点角求真实参考椭圆的日心距离，由1到5 AU平滑衰减。双尾几何、长度、亮度、彗发均为科普示意，不模拟太阳风、尘粒动力学、喷流、非引力项或行星摄动。

公共时间是累计展示秒：不同天体的公转和自转各自压缩，不对应单一现实日期。不从系统日期推算位置，也不用于过境预测或跨历元精确星历。界面的倍率只控制视觉时间推进。

## 实现与验证
`kepler.ts`：闭合椭圆、倾角、定向、初始相位和方向；高偏心率数值回退。`comet.ts`：科学/展示参数隔离、日心距离和活动强度、标准/轻量预算。`CometAppearance.tsx`：分层彗发、直离子尾和弯曲尘埃尾，不继承彗核自转。

数值验证覆盖高偏心率残差、轨道闭合、近日/远日距离、倾角、方向、圆轨道兼容、近太阳加速、公共时钟定位/暂停/倍率。浏览器检查入口跟随、跳转同步地球与彗核、恢复播放、特效开关、隐藏选中目标、手机取景、三语与控制台。
