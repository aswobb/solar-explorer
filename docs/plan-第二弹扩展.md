# Solar Explorer 实施计划 · 第二弹扩展

相关计划：[基础版](plan-基础版.md)

更新日期：2026-11-02

目标：在现有太阳与八大行星 demo 上，分阶段加入天然卫星、小行星带、矮行星、柯伊伯带、彗星、奥尔特云、人造卫星与探测器，形成从行星局部到太阳系外围的分层探索体验。

本文为后续实施计划；未勾选项目均未完成。每阶段形成可独立演示的版本，验收通过后进入下一阶段，不要求一次完成所有内容。

## 现有基础与约束

- 已有：太阳与八大行星、自转公转、暂停与速度控制、选择与镜头跟随、地球昼夜/云/大气、土星环、太阳效果、中日英、标准/轻量画质。
- 当前 `BodyId` 仅包含太阳与八大行星；`Planet.orbit.center` 固定为太阳；`SolarSystem.tsx` 按平铺列表更新位置，需要扩展父子轨道层级。
- 科学数据与显示参数继续分离。现有非线性时间压缩、展示尺寸及距离不代表真实比例或当前星历。
- 保留静态部署方式。第一轮不依赖后端、实时轨道接口或完整 N 体引力模拟。
- 新增资料、图片与模型均记录来源、适用日期和授权；新增界面与图鉴同步提供中日英。

1. 功能可从界面到达，能退出或返回，隐藏目标时不存在悬空选择。

3. 新增文本覆盖中日英，标准/轻量模式与减少动态效果均有可用路径。
4. 相关行为测试、类型检查、构建及实际浏览器关键流程通过，无已知阻断回归。
5. 记录性能变化与未解决限制，更新对应文档后再勾选完成。
