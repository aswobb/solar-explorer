# 操作ガイド

[READMEへ戻る](../README.md)

## 探索の流れ

1. 読み込み後に太陽系の全景が表示されます。天体または画面下の名前を選びます。小さな惑星は名前一覧から選ぶと確実です。
2. カメラが選択した天体へ近づき、名前・輪郭・解説が切り替わります。移動中も別の天体を選ぶか、全景へ戻れます。
3. ドラッグやボタンで観察します。追従中は天体が公転しても注視点が同じ天体に追従します。
4. 解説の代表値・単位を読み、「出典・定義」で参照資料を確認します。幅960px以下では「解説を見る」で本文へ移動し、「↑ 3D表示に戻る」で戻れます。
5. 「全景に戻る」または「選択を解除」で全体表示に戻ります。再生状態と経過時間はリセットしません。

## 入力方法

| 操作 | マウス | タッチ | キーボード |
|---|---|---|---|
| 選択 | 球体・名前をクリック | 球体・名前をタップ | 名前へTab、Enter / Space |
| 回転 | 左または右ドラッグ | 1本指でドラッグ | 「キーボードで視点を操作」の枠で方向キー |
| 拡大・縮小 | ホイール、画面のボタン | 2本指、画面のボタン | ボタンへTab、Enter / Space |
| 解説・復帰 | 各リンク・ボタン | 各リンク・ボタン | Tabで移動、Enter |
| 表示設定・出典 | 見出しをクリック | 見出しをタップ | 見出しでEnter / Space |

方向キーは視点操作の枠にフォーカスがあるときだけ使います。1回15度で、上下は範囲制限があります。Tab / Shift+Tabで枠から出られます。平行移動は無効です。カメラ移動中は回転・ズームを待ちます。
描画領域の外では通常のページスクロールができます。天体一覧は横スクロールできます。ドラッグや2本指操作を単純な天体タップとして扱わないよう判定しています。

## 再生と言語

「一時停止」「再生」で運動を止めたり再開したりできます。表示速度は0.25× / 0.5× / 1× / 2× / 5×です。速度は表示用の時間に適用され、物理的な実速度ではありません。タブが非表示になると運動を休止します。
言語はヘッダーで日本語・中文・Englishから選べます。ブラウザ内に言語だけを保存し、保存できない環境でも切り替えは使えます。画質、再生、選択などは再読込で初期状態に戻ります。

## 表示設定

| 項目 | 変更内容 |
|---|---|
| 動きを減らす | オンにした時点で停止。カメラは即時移動、ドラッグの慣性は無効。手動での再生は可能。オフでも自動再開しない |
| 表示品質 | 標準はピクセル比上限1.5、軽量は1。軽量は主体球体の分割と星点を減らす。画像と特殊効果は別設定 |
| 表面テクスチャ | 全体の画像使用を切り替え。オフは純色の基本表示、地球・太陽の画像依存効果も停止 |
| 地球の昼夜・雲・大気 | 夜側の合成夜景、雲、青い縁の追加表示 |
| 土星の環 | 環の表示。全テクスチャがオフでも簡易的な無地の環を表示 |
| 太陽の表面・コロナ | 動的な表面と透明な日冕・光彩。オフは静的な表面画像 |
| 太陽の光彩 | オフ / 弱 / 標準 / 強。オフでも細いコロナは残る。コロナも消すには上の効果をオフ |

設定を折りたたんでも値は保持します。端末の「動きを減らす」がオンなら、それを優先してページ側の同設定を固定し、説明を表示します。端末側で変更できます。画像が失敗した場合は折りたたみ見出しにも簡易表示の案内が出ます。

## 数値を読むとき

表示上のサイズ・距離・速さと、解説の実際の代表値は別です。半径は直径ではなく平均半径、恒星自転周期は昼夜の長さとは異なり、軌道長半径は現在の太陽との距離ではありません。自転の逆行は時間を負で表示せず、方向を別記します。
太陽の日心公転は適用外です。太陽の自転は緯度16度での代表周期を使い、緯度による差動回転は再現しません。値の丸め方や出典は解説に記載しています。

## 困ったとき

| 症状 | 確認すること |
|---|---|
| URLにつながらない | 開発サーバーが起動しているか、ターミナルのポートとURLが一致するか。`#body-details` は位置指定で接続失敗の原因ではない |
| スマートフォンから開けない | 同じネットワークで、`--host 0.0.0.0` のNetwork URLを使っているか。PCのサーバーを起動したままにする |
| 太陽の近くに立方体がある | 開発URLの `?debugScene=1` を外す。照明調査用の物体で、正式な天体ではない |
| WebGLを使えない | WebGL2対応、ブラウザ設定やハードウェアアクセラレーションを確認。「もう一度試す」または再読み込み |
| 展示がエラーになった | 「もう一度試す」で再構築。選択や画質等は初期状態に戻る |
| 一部の画像が出ない | 該当箇所だけ基本表示で続行。表面画像は全テクスチャ、雲・夜景は地球効果、環は環のチェックを入れ直して再試行 |
| 動きが重い | 軽量へ切り替える、不要な追加効果をオフにする、一時停止する。一定FPSは保証していない |
| 画面回転後に近すぎる | 同じ天体を再選択するか、全景へ戻って取景し直す |

詳細な検証範囲は[検証記録](VALIDATION.md)を参照してください。
