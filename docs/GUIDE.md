# 操作ガイド

[READMEへ戻る](../README.md)

## 探索の流れ

1. 読み込み後に太陽系の全景が表示されます。天体または画面下の名前を選びます。小さな惑星は名前一覧から選ぶと確実です。
2. カメラが選択した天体へ近づき、名前・輪郭・解説が切り替わります。移動中も別の天体を選ぶか、全景へ戻れます。
3. ドラッグやボタンで観察します。追従中は天体が公転しても注視点が同じ天体に追従します。
4. 解説の代表値・単位を読み、「出典・定義」で参照資料を確認します。幅960px以下では「解説を見る」で本文へ移動し、「↑ 3D表示に戻る」で戻れます。
5. 「全景に戻る」または「選択を解除」で全体表示に戻ります。再生状態と経過時間はリセットしません。

## 入力方法

| 操作 | マウス | タッチ | キーボード |
|---|---|---|---|
| 選択 | 球体・名前をクリック | 球体・名前をタップ | 名前へTab、Enter / Space |
| 回転 | 左または右ドラッグ | 1本指でドラッグ | 「キーボードで視点を操作」の枠で方向キー |
| 拡大・縮小 | ホイール、画面のボタン | 2本指、画面のボタン | ボタンへTab、Enter / Space |
| 解説・復帰 | 各リンク・ボタン | 各リンク・ボタン | Tabで移動、Enter |
| 表示設定・出典 | 見出しをクリック | 見出しをタップ | 見出しでEnter / Space |

方向キーは視点操作の枠にフォーカスがあるときだけ使います。1回15度で、上下は範囲制限があります。Tab / Shift+Tabで枠から出られます。平行移動は無効です。カメラ移動中は回転・ズームを待ちます。
描画領域の外では通常のページスクロールができます。天体一覧は横スクロールできます。ドラッグや2本指操作を単純な天体タップとして扱わないよう判定しています。

## 再生と言語

「一時停止」「再生」で運動を止めたり再開したりできます。表示速度は0.25× / 0.5× / 1× / 2× / 5×です。速度は表示用の時間に適用され、物理的な実速度ではありません。タブが非表示になると運動を休止します。
言語はヘッダーで日本語・中文・Englishから選べます。ブラウザ内に言語だけを保存し、保存できない環境でも切り替えは使えます。画質、再生、選択などは再読込で初期状態に戻ります。

## 表示設定

| 項目 | 変更内容 |
|---|---|
| 動きを減らす | オンにした時点で停止。カメラは即時移動、ドラッグの慣性は無効。手動での再生は可能。オフでも自動再開しない |
| 表示品質 | 標準はピクセル比上限1.5、軽量は1。軽量は主体球体の分割と星点を減らす。画像と特殊効果は別設定 |
| 表面テクスチャ | 全体の画像使用を切り替え。オフは純色の基本表示、地球・太陽の画像依存効果も停止 |
| 地球の昼夜・雲・大気 | 夜側の合成夜景、雲、青い縁の追加表示 |
| 土星の環 | 環の表示。全テクスチャがオフでも簡易的な無地の環を表示 |
| 太陽の表面・コロナ | 動的な表面と透明な日冕・光彩。オフは静的な表面画像 |
| 太陽の光彩 | オフ / 弱 / 標準 / 強。オフでも細いコロナは残る。コロナも消すには上の効果をオフ |

設定を折りたたんでも値は保持します。端末の「動きを減らす」がオンなら、それを優先してページ側の同設定を固定し、説明を表示します。端末側で変更できます。画像が失敗した場合は折りたたみ見出しにも簡易表示の案内が出ます。

## 数値を読むとき

表示上のサイズ・距離・速さと、解説の実際の代表値は別です。半径は直径ではなく平均半径、恒星自転周期は昼夜の長さとは異なり、軌道長半径は現在の太陽との距離ではありません。自転の逆行は時間を負で表示せず、方向を別記します。
太陽の日心公転は適用外です。太陽の自転は緯度16度での代表周期を使い、緯度による差動回転は再現しません。値の丸め方や出典は解説に記載しています。

## 困ったとき

| 症状 | 確認すること |
|---|---|
| URLにつながらない | 開発サーバーが起動しているか、ターミナルのポートとURLが一致するか。`#body-details` は位置指定で接続失敗の原因ではない |
| スマートフォンから開けない | 同じネットワークで、`--host 0.0.0.0` のNetwork URLを使っているか。PCのサーバーを起動したままにする |
| 太陽の近くに立方体がある | 開発URLの `?debugScene=1` を外す。照明調査用の物体で、正式な天体ではない |
| WebGLを使えない | WebGL2対応、ブラウザ設定やハードウェアアクセラレーションを確認。「もう一度試す」または再読み込み |
| 展示がエラーになった | 「もう一度試す」で再構築。選択や画質等は初期状態に戻る |
| 一部の画像が出ない | 該当箇所だけ基本表示で続行。表面画像は全テクスチャ、雲・夜景は地球効果、環は環のチェックを入れ直して再試行 |
| 動きが重い | 軽量へ切り替える、不要な追加効果をオフにする、一時停止する。一定FPSは保証していない |
| 画面回転後に近すぎる | 同じ天体を再選択するか、全景へ戻って取景し直す |

詳細な検証範囲は[検証記録](VALIDATION.md)を参照してください。


## 图层与视图（P0）

场景下方新增“图层与视图”，可关闭轨道线或天体名称列表。选择天体后显示局部视图状态，点击“返回上一级”回到太阳系全景。关闭名称列表不隐藏天体，仍可点击场景选择。卫星与外围区域将在后续阶段提供，距离、大小与时间仍使用展示比例。


## P1：探索地球与月球

1. 打开页面即自动播放。在名称列表或场景中选择地球。
2. 点击地球详情中的“探索地月系统”，或场景上方的同名快捷按钮。
3. 镜头平滑拉到同时容纳地球和月球的视角；点击月球或名称列表中的“月球”，进入跟随近景。
4. “返回上一级”依次返回地月系统、地球近景、太阳系全景。“返回总览”直接回到全景。
5. 图层中的“显示月球”可以手动切换。在月球近景关闭它，会先返回地球，避免继续跟随隐藏目标。

所有入口都是原生按钮，可用 Tab 聚焦、Enter/空格触发；现有键盘视角、触控、暂停和倍率控制继续可用。地月距离被压缩，半径与轨道为展示比例；月球自转与展示公转同步。资料值按 NASA 的真实参考值显示，不代表画面尺寸或当前星位。


## P2：木星与土星系统

- 名称列表下方的“地月系统 / 木星系统 / 土星系统”可直接切换系统；也可在对应行星详情中点击“探索卫星系统”。
- 木星系统提供木卫一、木卫二、木卫三、木卫四，土星系统提供土卫六。可以点击模型、系统中的悬浮名称，或底部卫星列表选择并跟随。
- 卫星详情中的父天体按钮返回所属系统；“返回上一级”依次回到父系统、父行星近景、全景。“返回总览”直接退出局部视图。
- “显示天然卫星”统一控制六颗已收录卫星；局部视图自动打开，手动关闭时返回父行星。关闭“天体名称”会隐藏场景标签和名称列表，模型仍可点击。
- 悬浮名称只在系统视图且目标足够大时出现；父行星遮挡、标签重叠或超出画面时隐藏，可继续用下方列表选择。
- 土星系统的取景保留土星环和土卫六完整轨道；土卫六使用带暖色的地表拼接图，是观察地表的示意，并非穿过浓厚大气的自然色外观。


土星系统现已收录七颗卫星：土卫一、二、三、四、五、六和八。名称列表按轨道远近排列，手机上可横向滚动。进入任意卫星后可通过父天体按钮返回完整土星系统。轨道间距与小卫星尺寸为可辨认性做了独立调整，未增加喷流或地形高度动画。


## P3：小行星带

默认全景可见火星与木星之间的碎石带。使用“图层与视图 → 小行星带”开关控制背景群体和两颗代表天体。

名称列表新增“谷神星”“灶神星”，可以点击列表或模型，平滑接近并持续跟随，查看三语言资料。“返回上一级”回到全景。关闭正在观察的小行星带时会自动退出代表天体近景，不会跟随隐藏对象。手机上可横向滚动名称列表。

近景会降低背景碎石的不透明度。背景群体不可逐颗选择，也不影响行星点击。区域下方的说明与 NASA 链接解释其位置和示意性质；科学参考值不等于画面比例，谷神星归类为矮行星，灶神星归类为小行星。


## P4：外围矮行星与图鉴

1. 在系统导航中点击“探索太阳系外围”。镜头平滑拉远，柯伊伯带逐渐出现，外围名称可以点击。
2. 展开“天体图鉴 · 分类与查找”，选择“矮行星”，可看到已有谷神星和新增四颗，共五颗。可使用中文、日语或英文名称搜索，与当前界面语言无关。
3. 点击结果进入近景。冥王星有 NASA 表面地图；阋神星、妊神星、鸟神星明确使用外观示意。阋神星归于散射盘，不在主环带中。
4. “返回上一级”从外围天体回到外围视图；“返回进入前的天体”恢复原先的行星或卫星。未从具体目标进入时，该按钮返回行星区。“返回总览”直接恢复默认行星全景。
5. 关闭“柯伊伯带与外围矮行星”也会退出隐藏目标的跟随。进入卫星系统时，不显示外围天体。分类查询保持可用，可再从图鉴选择。

外围距离与天体大小经过独立压缩，不能从屏幕测量真实距离。背景星点不构成物理边界；盘状粒子不是实际小天体目录，真实椭圆与当前星位尚未模拟。

### P5：观察哈雷彗星
选择“探索哈雷彗星”或在图鉴的“彗星”分类选择哈雷。点击“跳到近日点”观察双尾，点击“跳到远日点”观察其衰减；跳转会同步整个场景并暂停，点击继续播放恢复。轨道使用现有图层开关；“彗发与双尾”只控制特效，“显示哈雷彗星”控制目标可见性。隐藏当前彗星会返回全景。时间读数为展示秒，并非现实日期。

### P6：探索奥尔特云
使用场景下方01行星区、02柯伊伯带、03奥尔特云逐级拉远。“返回原来的视角”恢复进入外围之前的天体或卫星系统，“返回柯伊伯带”退回上一级，01按钮返回行星全景。远景可拖动旋转、缩放；AU标尺使用对数比例。推测结构与不确定范围在画面和说明中标示。

### P7：人造卫星和深空专题
通过“人造航天器”选择地球轨道、旅行者1号或新视野号。在地球轨道中点击模型、名称或资料卡跟随；关闭人造卫星会回到地球轨道全景。深空专题可点击关键事件、拖动时间线、播放、切换倍率、跟随探测器或查看全路线；默认暂停。退出专题恢复原来的天体/卫星视图、时钟与相机。资料日期和路线示意说明在专题面板内可见。

### P8：统一入口与设置
场景下方“探索导航”统一提供全景、父级、行星系统、航天器和三级外围入口。图鉴可直接搜索32个目标，天然卫星和人造卫星分别筛选。图层按当前视图显示适用选项，显示设置在任务专题内同样可用。减少动态效果暂停所有时钟并立即切换镜头，点云静态显隐；刷新仍默认播放。
