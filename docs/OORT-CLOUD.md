# P6：奥尔特云与远景尺度

## 导航与上下文
三段入口：行星区 → 柯伊伯带 → 奥尔特云。每段镜头有平滑过渡；远景明确切换距离比例，不冒充同一线性物理空间。支持返回柯伊伯带、返回原来的视角、行星区一键返回。进入外围前保存完整 body/system 视图，地球、卫星及局部系统均可恢复。暂停不阻断镜头导航；公共模拟时钟保持连续。

## 科学边界
来源为 [NASA Oort Cloud](https://science.nasa.gov/solar-system/oort-cloud/) 与 [NASA Oort Cloud Facts](https://science.nasa.gov/solar-system/oort-cloud/facts/)，采集2026-11-02。内缘代表估计约2,000–5,000 AU，外缘约10,000–100,000 AU；不同估计存在差异，边界并不确定。奥尔特云尚未直接观测，球壳仅作结构说明；不模拟可能更复杂的内云形态或测量密度。光点没有虚构名称，也不是已发现对象目录。

## 远景坐标
`oortField.ts` 分别保存估计范围、采用的示意采样范围与显示半径。点云在5,000–100,000 AU范围采样，采用独立于近景的有界坐标：

r = 80 × ln(1 + AU / 50) / ln(1 + 100000 / 50)

该单调、可逆的对数映射将最大范围固定在80场景单位。AU不直接进入相机或深度缓冲；标尺显示距太阳的估计AU值，不从相机距离推断真实位置。太阳标记、柯伊伯盘厚度和点大小经过可见性调整。太阳中心、30–50 AU盘与球壳共用这一远景径向映射，不与近景显示坐标混用。

## 预算与生命周期
标准8,000个球壳采样点、1,200个柯伊伯盘点；轻量2,000与300。确定性种子和稳定前缀避免切换画质时整体随机跳变。无新增纹理、虚构可选对象或逐点DOM。远景组件仅在oort视图挂载，退出由R3F卸载/释放几何和材质。近景SolarSystem保持挂载并隐藏以保持公共时钟，隐藏期间忽略天体点击；远景不叠加装饰星空，以区分结构点云与背景星。

## 验证
73项单元/数值回归测试通过：对数映射可逆、球壳界限及各轴分布、确定性与预算前缀、柯伊伯盘形态、横竖屏相机包络。Edge浏览器验证地球→柯伊伯→奥尔特→地球、系统视角恢复、暂停/键盘导航、轻量预算、卸载、手机取景与三语。截图见 `showcase/oort-cloud.png`。不宣称已完成实体手机GPU性能测试。

窄屏画布（宽度不足600px）自动封顶轻量预算：2,000球壳点、300盘点；不改变其他场景的画质选择。
