## 状態と時間

選択IDの正本はBasicSceneが所有し、ID変更時のみAppに通知します。資料用に受け取ったIDは座標の複製ではありません。カメラ命令には増加するIDを付け、同じ天体の再選択も新しい取景命令にします。
座標・回転・時刻・補間途中の値はrefに保持します。`useFrame`ごとにReact状態を更新しないため、ページ全体の再レンダリングをアニメーションの手段にしません。

表示時間はフレームのdeltaから積算します。`motion.ts`では次のルールを使います。

```text
time += min(delta, 0.25) × 表示倍率
表示公転周期 = 40秒 × (実公転日数 / 365.2日)^0.35
表示自転周期 = 12秒 × (abs(実自転時間) / 23.9時間)^0.25
```

公転と自転の時間尺度は別です。実周期の大小関係を残しつつ、観察しやすいよう非線形に圧縮します。逆行は元データの自転符号から一度だけ適用します。長いフレームを制限するので、極端に遅い描画時は実時間に追いつく方式ではありません。
停止・非表示タブでは時刻を進めず、再開後の最初のフレームも積算から除外します。停止中でもカメラ命令や画像完了は描画できます。

## 1フレームの順序

| 優先度 | 処理 |
|---|---|
| -2 | SolarSystemが時刻と天体の位置・自転を更新 |
| -1.5 | 地球の太陽方向・雲と太陽の位相を同じ時刻から更新 |
| -1 | DreiのOrbitControlsが手動入力を反映 |
| 0 | OverviewCameraが移動または追従を処理 |

正の優先度でレンダリングを乗っ取らず、R3Fの描画を使います。時刻更新後のworld positionをカメラが読むため、別々のReact状態による位置のずれを避けます。

## カメラの状態遷移

`overview → focusing → following → returning → overview` を使います。別の天体を選べば現在位置からfocusingを開始し直します。
移動中はOrbitControlsを無効化し、手動入力との競合を避けます。終了後は有効化し、天体中心を基準に操作できます。followingでは前フレームとの天体位置の差分をカメラ位置と注視点の両方へ加え、手動で決めた相対視角を保ちます。
取景は球体だけでなく土星の環・太陽のコロナを含む外縁を使います。約1.35秒の5次補間で移動開始・終了を滑らかにし、フレームdeltaは0.1秒まで積算します。非常に遅い環境では実時間で1.35秒とは限りません。
キーボードも同じ命令経路を使い、球面座標で15度ずつ回転します。距離と注視点を保ち、極角を制限します。画面変更時に手動視角を強制リセットしないため、必要なら再選択して取景し直します。

## 材質と代替表示

地球はworld法線と地球中心から太陽への方向の内積で昼夜を判定し、夜側だけ合成夜景を加えます。雲は透明な球殻、大気は視線に対する縁の近似です。
土星の環は球体と傾きを共有する独立した平面で、径方向UVと透過画像を使います。球体の深度に対してテストし、環は深度を書かずに合成します。環の投影は計算しません。
太陽は表面UVの小さな変形とノイズ、透明球殻の局所的な加算合成を使います。画面全体のBloomは使いません。周期位相を小さな範囲に保ち、uniformを更新します。
追加効果にはオフにできる基本経路があります。画像失敗は該当部分だけを基本表示に戻し、シーン全体の例外にはしません。

## リソースと描画負荷

画像は各hookが所有し、無効化・アンマウント時に15秒のタイマーを解除してリクエストをキャンセルし、Textureをdisposeします。遅れて到着したコールバックが表示を復活させないよう制御します。読み込み処理そのもののHTTP転送を中断する仕組みではありません。
宣言的なgeometry/materialと、R3Fが生成したrendererはR3Fのライフサイクルで解放します。星点数を変えるときはgeometryを数量キーで作り直し、古いbufferも解放対象にします。毎フレームこれらを作り直しません。

- 標準：DPR上限1.5、一般球体32×24、地球/太陽64×48、星点2400＋明点180。
- 軽量：DPR上限1、一般球体24×16、地球/太陽32×24、星点800＋明点60。

明点は同じ点群の一部を重ねるため、星の種類が追加されるわけではありません。雲・大気・コロナ・環の細分や画像解像度は画質設定で変更しません。
再生またはカメラ移動中はalways、それ以外はdemand描画です。demandでも入力、慣性の収束、画像完了や設定変更など必要な更新を描画します。測定結果と限界は[描画負荷の測定](PERFORMANCE.md)に分離しています。

## 多言語・配慮設定・障害

辞書のキー構造を日本語から型として共有し、数値と単位はデータに保存、表示はIntl.NumberFormatで整形します。言語だけをlocalStorageに保存し、読み書きが失敗しても日本語へのフォールバックと画面内切り替えを維持します。
システムの「動きを減らす」設定をuseSyncExternalStoreで監視し、ページ設定との論理和を使います。オンで停止・即時カメラ・慣性なしへ切り替え、オフでも自動再開しません。
WebGL2の一時プローブは直後にcontextを解放し、実際のcontext喪失はError Boundaryへ通知します。再試行は新しいシーンを構築します。Canvas内部の予備テキストにはボタンを置かず、見えないTab移動を防ぎます。

## テストの役割

純粋関数には軌道・時刻・取景・書式・ジェスチャー・画質・購読解除・画像解放のテストを置き、画像はハッシュと形式も照合します。CSSやDOM構造だけをなぞるテストは増やさず、選択・読み込み・例外復帰は実ブラウザで確認します。現在の証拠と未検証範囲は[検証記録](VALIDATION.md)を参照してください。
